# Contenu, sémantique et GEO

## Intention de recherche

Pour chaque page importante, identifier son intention principale parmi :
informationnelle ; commerciale ; transactionnelle ; locale ; navigationnelle ;
comparaison ; problème → solution ; recherche de service.

**UNE PAGE = UNE INTENTION PRINCIPALE.**

Ne pas créer plusieurs pages qui ciblent exactement la même intention. Éviter les pages
locales clonées.

## Keyword research

Lorsqu'un accès web / outils de recherche est disponible, identifier : mot-clé principal ;
variantes ; longue traîne ; questions ; entités associées ; recherches locales ; recherches
commerciales ; recherches informationnelles ; concurrents ; sujets manquants.

Ne pas bourrer le contenu de mots-clés. Le vocabulaire doit rester naturel.

## Title

Chaque page indexable doit avoir un title unique. Il doit décrire précisément la page,
correspondre à l'intention, être naturel, inclure le sujet principal lorsque pertinent,
éviter la répétition artificielle et être différencié des autres pages.

**NE PAS utiliser :** `Entreprise | Entreprise | Entreprise | Ville | Meilleur | Pas cher`

## Meta description

Chaque page stratégique doit avoir une meta description utile : expliquer clairement la
page, correspondre au contenu réel, encourager le clic, contenir le sujet lorsque naturel,
sans keyword stuffing.

## Headings

Vérifier : un H1 principal ; des H2 logiques ; des H3 lorsqu'ils apportent une hiérarchie
utile ; l'absence de titres uniquement décoratifs ; la cohérence entre headings et contenu.

Les headings doivent permettre de comprendre la page même en la parcourant rapidement.

## Contenu SEO

Le contenu doit répondre réellement à l'intention. Chaque page importante doit idéalement
répondre :

- Qu'est-ce que c'est ?
- Pour qui ?
- Où ?
- Comment ?
- Combien ?
- Pourquoi ?
- Quand ?
- Quelles alternatives ?
- Comment choisir ?
- Comment contacter l'entreprise ?

Adapter les questions au secteur.

**NE PAS générer artificiellement des centaines de pages.** Priorité à : utilité ;
précision ; originalité ; expertise ; preuve ; clarté.

## GEO — Generative Engine Optimization

Optimiser chaque page importante pour qu'un système IA puisse facilement comprendre :

```
QUI ?  QUOI ?  OÙ ?  POUR QUI ?
COMMENT ?  POURQUOI ?  COMBIEN ?  QUAND ?
```

Créer des passages autonomes et clairement formulés.

## Contenu citable par les IA

Favoriser : réponses directes ; définitions ; listes ; tableaux ; comparaisons ; étapes ;
FAQ ; données vérifiables ; exemples ; sources ; informations locales précises.

Éviter : paragraphes extrêmement vagues ; slogans sans information ; répétitions ; contenu
artificiellement gonflé ; affirmations invérifiables.

## Entités

Identifier les entités importantes : entreprise ; marque ; personne ; produit ; service ;
ville ; région ; secteur ; organisme ; technologie.

Maintenir une cohérence parfaite des noms. Si l'entreprise s'appelle « Garage Dupont », ne
pas alterner artificiellement entre « Garage Dupont », « Garage Automobile Dupont »,
« Dupont Auto », « Garage de Jean » — sauf si ces noms sont réellement utilisés.

## Schema.org

Utiliser JSON-LD lorsque pertinent. Identifier automatiquement le type adapté :
Organization ; LocalBusiness ; Service ; Product ; Article ; BreadcrumbList ; WebSite ;
Person ; FAQPage lorsque réellement pertinent et conforme aux règles applicables.

**NE JAMAIS inventer :** avis ; notes ; prix ; disponibilité ; certifications ; adresse ;
horaires.

Les données structurées doivent correspondre au contenu visible.

## SEO local

Pour les entreprises locales, vérifier : nom ; adresse ; téléphone ; horaires ; zone
desservie ; services ; coordonnées ; profils externes ; Google Business Profile ; Bing Places.

Maintenir la cohérence entre :

```
SITE → GOOGLE → BING → ANNUAIRES → RÉSEAUX → AUTRES PROFILS OFFICIELS
```

Créer des pages locales uniquement lorsqu'elles apportent une vraie valeur.

## SEO + GEO content engine

Pour chaque secteur, construire une architecture de contenu autour de :

```
PILIER
 → SERVICES
 → QUESTIONS
 → PROBLÈMES
 → COMPARAISONS
 → GUIDES
 → FAQ
 → LOCAL
```

Exemple garage :

```
Garage à Angoulême
 → Révision
 → Vidange
 → Freinage
 → Pneus
 → Diagnostic
 → Prix révision
 → Quand changer ses freins ?
 → Comment choisir ses pneus ?
 → Garage autour d'Angoulême
```

## E-E-A-T / confiance

Renforcer lorsque pertinent : expérience ; expertise ; auteur ; entreprise ; références ;
réalisations ; études de cas ; certifications réelles ; partenaires réels ; sources ;
informations de contact ; mentions légales.

**NE JAMAIS inventer une preuve d'autorité.**
