# Mesure et outils

## Bing / Copilot / AI Performance

Si Bing Webmaster Tools est disponible, vérifier : indexation ; sitemap ; crawl ; erreurs ;
recommandations ; AI Performance.

AI Performance permet de voir notamment : pages citées ; volume de citations ; tendances ;
grounding queries.

Utiliser ces données pour identifier les sujets où le site est déjà cité et ceux où il peut
améliorer son contenu.

**NE PAS interpréter une citation IA comme un classement Google.**

## IndexNow

Si le site est compatible, mettre en place IndexNow. L'utiliser après : création d'une page ;
modification importante ; suppression ; changement d'URL.

Ne pas envoyer des milliers d'URLs inutiles.

## Google Search Console

Si l'accès est disponible, vérifier : pages indexées ; pages exclues ; erreurs ; requêtes ;
impressions ; clics ; CTR ; positions ; Core Web Vitals ; sitemap.

Identifier les pages avec **fortes impressions + faible CTR** et proposer une optimisation
du title / de la meta description.

Identifier les pages avec **bonne position + faible conversion** et améliorer le contenu / le CTA.

## Analytics

Si Analytics existe, vérifier les conversions importantes : formulaire ; téléphone ; email ;
réservation ; devis ; achat ; CTA.

Le SEO doit être mesuré par **impact business**, pas uniquement par position.
